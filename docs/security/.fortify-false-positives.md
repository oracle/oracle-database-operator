# Fortify false-positive register

This is the review register for recurring local Fortify findings that have
already been analyzed. It is an internal engineering reference for reviewing
the generated FPR, XML, and PDF reports.

Before opening a new defect or repeating the analysis, check whether the
finding matches an entry below. A register entry does not replace the Fortify
audit/disposition in SSC; it records the approved rationale and must be
published with each local scan report.

## JSON Injection: PDB request payload

- **Finding IDs:** `43BBB36B947741A2C32370639AA7966E`, `43BBB36B947741A2C32370639AA7966F`
- **Category:** `JSON Injection`
- **Analyzer:** `dataflow`
- **Reported location:** `controllers/database/lrpdb_controller.go:2748`
- **Current serialization site:** `controllers/database/lrpdb_controller.go` at the `json.Marshal(payloadpdb)` call
- **Disposition:** False positive
- **Review:** `payload` is narrowed to `map[string]string` and serialized by Go's
  `encoding/json`. `json.Marshal` escapes keys and values and cannot interpret
  a map value as a raw JSON fragment. Attacker-controlled text therefore
  cannot add JSON fields or change the request structure before it reaches the
  HTTP body. There is no raw JSON concatenation in this path.
- **Separate code-quality note:** handle the ignored `json.Marshal` error when
  changing this code. That is not evidence of JSON injection.
- **Recommended Fortify disposition:** `False Positive`

## Cipher Suite Downgrade: deprecated PreferServerCipherSuites

- **Finding IDs:** `FE8445E7B66246B78CA71FEA170778D5`
- **Category:** `Insecure Transport`
- **Analyzer:** `structural`
- **Reported location:** `ordssrvs_status.go:135`
- **Disposition:** False positive
- **Review:** Fortify's finding concerns `tls.Config.PreferServerCipherSuites`. Go deprecated this field starting in Go 1.17 and ignores its value. This repository builds with Go 1.27.4, so the setting cannot cause the reported cipher-suite downgrade.
- **Recommended Fortify disposition:** `False Positive`
