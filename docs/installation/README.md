# Installation Documentation

Use these guides to install and administer Oracle AI Database Operator for Kubernetes.

| Guide | Use when |
| --- | --- |
| [Installation Methods](./INSTALLATION_METHODS.md) | Choosing and running a supported install path (manifests, OKE add-on, OperatorHub, OpenShift) and verifying the installation |
| [Manual Build and Deployment](./OPERATOR_INSTALLATION_README.md) | Building a custom operator image and deploying it manually |
| [Managing Installation Scope](./OPERATOR_SCOPE_MANAGEMENT.md) | Configuring namespace-scoped vs cluster-scoped installs, `WATCH_NAMESPACE`, and RoleBindings |

Start with the root [README — Install the Operator](../../README.md#install-the-operator) for the default path, then open the guide that matches your method.
